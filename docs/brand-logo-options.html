fler logo direction board

The wordmark is fixed as fler. F monograms are now the default direction, with a few abstract marks included so the identity does not collapse into a plain letter icon.

Base color candidates

01. Graphite + Signal Green + Sky

Recommended. B2B dashboard, AI search, data freshness all fit.

02. Deep Navy + Lime

More energetic. Good for creator discovery, slightly louder.

03. Charcoal + Blue + Amber

Enterprise analytics tone. Amber works for campaign signals.

04. Ink + Violet + Teal

More AI-like. Use carefully so the UI does not become generic.
